# Navisworks utilities

Unofficial Windows utilities for working with Autodesk Navisworks

Note: Autodesk® and Navisworks® are trademarks or registered trademarks of Autodesk, Inc. This project is not affiliated with, sponsored, or endorsed by Autodesk.

## Tools
- Appearance Profiler migration — fixes malformed XML produced from importing older .dat files, including AVEVA/PDMS rules.
  - See: [Navisworks Appearance Profiler Migration](NavisworksAppearanceProfilerMigration/)

## Requirements
Each tool documents its own requirements. The Appearance Profiler migration tool is tested with Python 3.13 with Tkinter.
